
# Habibti Care Services Website

A responsive business website for Habibti Care Services, a professional cleaning company providing residential, commercial, and specialised cleaning services across selected locations in Nigeria.

## About the Project

The website provides visitors with information about Habibti Care Services, its cleaning solutions, business offers, and booking process.

It also gives potential customers a direct way to contact the business, request a quote, and make enquiries.

## Features

- Responsive design for mobile, tablet, and desktop.
- Business introduction and About section.
- Cleaning services organised into categories.
- Special offers and booking instructions.
- Why Choose Us section.
- Before-and-after cleaning gallery.
- Contact information and enquiry form.
- Direct WhatsApp contact links.
- Social media links.
- Accessible Bootstrap icons.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- JavaScript
- Google Fonts

## Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Open the Project

Navigate into the project folder:

```bash
cd habibti-cleaning-website
```

### 3. Run the Website

Open `index.html` in your browser.

For a better development experience, use the Live Server extension in Visual Studio Code.

## Customisation

- Update website content in `index.html`.
- Modify colours, typography, spacing, and layouts in `css/style.css`.
- Update interactive functionality in `js/script.js`.
- Replace or add business images inside `assets/images/`.
